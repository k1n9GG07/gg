## 🧩 Этапы выполнения КТ (объединённые результаты)

### Этап 1. Анализ предметной области (на базе КТ №1)
- **Выявлены объекты** (договоры, сметы, сотрудники, точки выдачи, клиенты, заказы и др.)
- **Сформированы сущности** для реляционной модели.
- **Определены атрибуты** и **ключевые элементы данных** (первичные ключи).
- **Итоговые сущности**:
  - Перечень договоров
  - Сметы на поставку
  - Сотрудники фирмы
  - Точки выдачи
  - Клиенты
  - Заказы клиентов
  - Должности

### Этап 2. Проектирование функциональной схемы и ролей (КТ №2)
- **Роли пользователей**: клиенты, сотрудники фирмы, поставщики.
- **Подсистемы**:
  - *Учёт товаров* (поставки, остатки, сметы)
  - *Заказ и доставка* (оформление, отслеживание, выдача)
- **Функциональная схема** (см. файл `KT2_13_вариант_Токмаев.docx` и встроенное изображение).

### Этап 3. Проектирование словаря данных (КТ №5)
- Для каждой сущности определено:
  - логическое и физическое имя поля
  - тип данных (INT, VARCHAR, DATE, DECIMAL)
  - обязательность (NULL / NOT NULL)
  - ограничения (уникальность, маски ввода, внешние ключи, допустимые значения)
- Примеры ограничений:
  - Логин: длина ≥ 8 символов
  - Пароль: минимум 1 заглавная, 1 строчная, 1 цифра, 1 спецсимвол
  - Номер зачётной книжки: маска `ЗК-000000-YY`
  - Дни недели: кроме воскресенья
  - Дата создания группы ≥ текущей даты

### Этап 4. Демонстрация проекта
- Реализован **демонстрационный сайт** (исходный код + GitHub Pages):  
  🔗 [https://k1n9gg07.github.io/delivery-site/](https://k1n9gg07.github.io/delivery-site/)
- Сайт иллюстрирует основные сценарии:
  - просмотр товаров
  - оформление заказа
  - отслеживание статуса
  - личный кабинет клиента
